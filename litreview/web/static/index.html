RUN DETAILS

快速使用

  1. 上传题录

    可全选同格式的多个分卷；不要把相同文献的 RIS 和 TXT 同时上传。

  2. 写清判据

    每条判据分别描述问题、纳入、排除和边界，判据组合决定整体结论。

  3. 先 Mock，后小样本

    Mock 仅用于验证流程，不是真实筛选。真实模型在 .env 中配置密钥，页面不保存密钥。

  4. 全量运行与导出

    评审员独立并行评审，完成后统一仲裁；可导出纳入文献和完整审计记录。
