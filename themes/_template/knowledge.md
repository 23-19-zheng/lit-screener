# 领域知识库（RAG 检索源，可选）

每个 `## ` 标题为一条独立知识条目，筛选时按与题录的相似度检索 top-k 注入评审 prompt。

条目写作要点：
- 保持简短（100~300 字）、定义式，聚焦**术语消歧**与**技术边界**（帮 LLM 校准判定口径）；
- 写"易混淆情形怎么判"，不要写百科式背景（那只会稀释检索）；
- 中英文术语都写上（检索是字符级匹配，英文摘要需要英文术语命中）。
- 本文件可以删除（config 的 knowledge 段也删掉或留空）——RAG 是增量项，不是必需项。

某术语（英文原词）指……。判定要点：出现 X 不等于 Y；A 与 B 的区分是……。若文献标题/摘要出现
"英文短语"，属 X 类。
